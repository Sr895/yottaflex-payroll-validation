# Submission checklist

- [ ] Create and activate `.venv`.
- [ ] Install dependencies with `python -m pip install -r requirements.txt`.
- [ ] Run `python main.py`.
- [ ] Confirm 3,000 employees and 100,000 source records in the console.
- [ ] Confirm all five anomaly rule codes appear.
- [ ] Confirm reconciliation reports at least one intentional failure.
- [ ] Confirm approved export contains approved rows only.
- [ ] Run `python -m pytest -q`.
- [ ] Inspect `reports/` and `data/ground_truth/`.
- [ ] Review README and remove any local secrets.
- [ ] Create a public GitHub repository and push the project.
